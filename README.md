# CryptoPulse - Live Price Tracker

Real-time cryptocurrency price tracker with live market data, sparkline charts, and search functionality

## Features

- Live prices for top 50 cryptocurrencies with sparkline 7-day charts
- Search and filter coins by name or symbol
- Market cap, volume, BTC dominance stats
- Color-coded price change badges (1h, 24h, 7d)
- Auto-refresh every 60 seconds
- Responsive dark theme with glassmorphism cards and animated gradients

## Tech Stack

- **Framework:** Next.js 16 (App Router, TypeScript)
- **UI:** shadcn/ui + Tailwind CSS
- **Animations:** Framer Motion
- **API:** CoinGecko Free API
- **Deployment:** Vercel
